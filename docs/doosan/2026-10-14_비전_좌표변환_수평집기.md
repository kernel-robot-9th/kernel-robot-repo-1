## 1. YOLO 학습 결과 분석과 보강 (v2)
**분석**
- 검증 점수(mAP50)가 1 epoch부터 0.995로 고정 → 검증 사진 3장이 학습 사진과 같은 장면이라 **점수로는 실제 성능을 판단할 수 없음**
- 학습 데이터 252장은 실제로는 장면 12개를 증강한 것 → 카메라 위치·조명·가림 상황이 부족

**스트레스 테스트** (기존 사진 15장에 변형을 걸어 재현율 측정, `tools/stress_test.py`)

| 상황 | v1 | v2 |
|---|---|---|
| 원본·어둡게·멀리·기울기 15°·옆에서 보기 | 100% | 100% |
| 노란 조명 | 95.6% | **100%** |
| 흔들림 블러 | 90.0% | **100%** |
| 컵 50% 가림 | 61.1% | **96.7%** |

- v2: 흔들림·조명색·부분 가림·로봇팔 가림 증강 추가, 150 epoch (best 118 epoch)
- 진열대를 **15° 기울여도 인식에는 문제 없음** → 기울기는 로봇이 잡기 편한 쪽으로 결정해도 됨
- 실시간 확인: 12개 전부 정답, 신뢰도 0.95~0.97, 약 30 FPS

## 2. 비전 ROS 노드 `shelf_vision`
- 요청 1번에 5장 촬영 → 흐린 프레임 제거 → 3장 이상에서 보인 물체만 인정(다수결)
- 실행: `ros2 launch couping vision.launch.py` (YOLO 가 든 `~/venv/yolo` 로 실행)

| 인터페이스 | 내용 |
|---|---|
| `/couping/vision/detect` (Trigger) | 인식 1회, 결과 JSON |
| `/couping/vision/cmd` → `/status` | `start` → `done` (다른 로봇 노드와 같은 방식) |
| `/couping/vision/detections` | 종류, 신뢰도, 박스, 카메라 3D, **로봇 좌표 `base_mm`**, 층·칸 번호 |
| `/couping/vision/targets_base` | 컵 중심 위치 (로봇 base_link 기준) |
| TF | `base_link → camera_color_optical_frame` |

## 3. 위치 추정 검증
- 60프레임 동안 컵 12개 3D 좌표 측정 (`tools/position_check.py`)
- **반복 정밀도 ±0.2~0.8mm**, 줄자 실측과 일치
- **투명 컵 문제 해결**: 박스 가운데 깊이를 쓰면 일부 컵이 깊이 1~46%만 잡힘 → **박스 안쪽에서 가까운 쪽 20% 깊이(컵 앞면)** 사용으로 12개 모두 정상
- 컵 중심 = 앞면 + 반지름(박스 폭으로 자동 추정, 약 32~36mm)

## 5. 그리퍼
- 수업 패키지 `dsr_gripper` 설치 (`~/couping_ws/src/dsr_study`)
- **방식 A(`gripper_service_a`) 사용**: 명령마다 시리얼 열고 닫음 → 연결이 끊긴 뒤에도 안정적
- 명령어 도구: `~/couping_ws/tools/gripper.sh open | close [힘] | <0~750>` (수동 모드면 자동으로 잠깐 auto 전환 후 복귀)
- 값 기준: 0 닫힘 / 375 50% / 450 40% 닫음 / 750 완전 열림

## 6. 수평 집기 (`couping.shelf_pick_test`)
- 강의 클릭 이동 테스트는 **위에서 내려가는 방식이라 선반을 넘어뜨릴 뻔함** → 진열대용으로 새로 작성
- 동작: 뒤로 빼기 → 컵 정면 15cm 앞에서 높이·좌우 맞춤 → 그리퍼 열기 → **2cm씩 수평 전진(매번 Enter)** → 잡기 → 1.5cm 들기 → 수평으로 빼기 → (선택) 진열대 앞 가운데로 이동
- 안전: 속도 20mm/s, 그리퍼 수평(±15°) 아니면 거부, 도달거리·최저높이 검사, `--dry-run`(계획만), 비상정지 후 원인 분석 반영
- `--teach`: 손으로 잡는 위치에 맞춰 **플랜지→잡는 점 오프셋** 저장 (잘못된 자세면 저장 거부)

```bash
python3 -m couping.shelf_pick_test --teach --row 1 --col 2                                  # 잡는 위치 저장
python3 -m couping.shelf_pick_test --row 1 --col 2 --open 375 --grip --carry-center --dry-run   # 계획 확인
python3 -m couping.shelf_pick_test --row 1 --col 2 --open 375 --grip --carry-center             # 실행
```

## 7. 발생한 문제와 대응
| 문제 | 원인 | 대응 |
|---|---|---|
| 선반을 밀어 **비상정지** | 그리퍼 길이를 200mm로 가정했으나 실제 약 250mm → 5cm 더 들어감 | 2cm씩 전진 + teach 오프셋 + 감속 |
| 카메라 위치 변경 | 비상정지·재설치 과정에서 카메라가 약 8° 기울어짐 | 캘리브레이션 재실시 (18:06) |
| bringup 연결 실패 | 컨트롤러 부팅 중 접속 / 제어권 거부 | 전원 후 **2분 대기** 후 bringup |
| DSR 명령이 가끔 멈춤 | 서비스 연결 전 첫 명령이 사라짐 | `couping/dsr_util.py` (연결 확인 후 명령) |
| 그리퍼 명령 무시 | 랜 끊김으로 SAFE_OFF / 그리퍼 루프 정지 | bringup + 그리퍼 서비스 재시작, 방식 A 사용 |
| **랜과 카메라 USB가 동시에 끊김** (여러 번) | 케이블 접촉 + 전기적 노이즈 추정 | 카메라 케이블 교체(USB 3 복구), 케이블 정리, 충전기 분리 권장 |
